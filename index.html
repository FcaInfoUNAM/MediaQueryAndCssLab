📐 Image Property Showcase

Each card demonstrates a different CSS image property. Check custom.css to see how each one works.

object-fit: cover

Fills the container, cropping the image as needed. Aspect ratio is preserved.

object-fit: contain

Fits the whole image inside the container. May leave empty space on the sides.

object-position

Controls which part of the image is visible when cropped with object-fit: cover.

width: 100% / max-width

The image stretches to fill its parent but never exceeds its natural size.

aspect-ratio

Locks a 16/9 ratio on the container so images are always proportional regardless of width.

background-size: cover

Using an image as a CSS background with background-size and background-position.
